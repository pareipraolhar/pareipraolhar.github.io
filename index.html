Parei pra Olhar: ferramenta de publicação

O Parei pra Olhar é um canal do YouTube de curiosidades e assuntos do momento.

Esta página apresenta a ferramenta própria que o canal usa para enviar e agendar os seus vídeos no YouTube, por meio dos Serviços de API do YouTube (YouTube Data API v3).

A ferramenta:

  • é de uso exclusivo do dono do canal Parei pra Olhar;
  • envia vídeos, miniaturas e legendas e agenda a data de publicação apenas no canal do próprio dono;
  • não acessa, não coleta e não armazena dados de outros usuários ou de outros canais;
  • não é oferecida ao público.
