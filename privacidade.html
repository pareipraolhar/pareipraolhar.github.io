Política de Privacidade: ferramenta de publicação do canal Parei pra Olhar

Última atualização: 24 de outubro de 2026

1. Quem somos

Esta ferramenta é usada exclusivamente pelo dono do canal do YouTube "Parei pra Olhar" para enviar e agendar os vídeos do próprio canal. Ela não é oferecida ao público.

2. Uso dos Serviços de API do YouTube

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, você concorda com os Termos de Serviço do YouTube (https://www.youtube.com/t/terms).

Os dados tratados por meio da API também estão sujeitos à Política de Privacidade do Google: https://policies.google.com/privacy

3. Quais dados a ferramenta acessa

Com a autorização dada pelo próprio dono do canal na tela de permissão do Google (OAuth 2.0), a ferramenta acessa apenas:

  • o nome e o identificador do canal autorizado, para conferir que o envio vai para o canal certo;
  • os vídeos, miniaturas, legendas, títulos, descrições e datas de publicação que o próprio dono envia e agenda.

    • A ferramenta não acessa dados de espectadores, comentários de terceiros, dados de outros canais nem informações de outros usuários.

4. Como os dados são usados

Os dados são usados somente para enviar os vídeos do dono do canal e agendar a publicação deles. Não há uso para publicidade, análise, venda ou qualquer outra finalidade.

5. Armazenamento

O código de autorização (token) fica guardado apenas no computador do dono do canal. Nenhum dado é enviado para servidores próprios ou de terceiros. Os arquivos de vídeo e os textos de publicação também ficam apenas nesse computador.

6. Compartilhamento

Nenhum dado é compartilhado, vendido ou cedido a terceiros. Os dados são enviados apenas ao próprio YouTube, para publicar os vídeos.

7. Cookies

A ferramenta não usa cookies e não coloca nenhum rastreador no dispositivo de ninguém.

8. Como revogar o acesso e apagar os dados

O acesso pode ser revogado a qualquer momento na página de permissões da Conta do Google: https://myaccount.google.com/connections (ou https://security.google.com/settings/security/permissions).

Ao revogar o acesso, o token salvo no computador deixa de funcionar e é apagado. Os dados obtidos pela API que ficam no computador são atualizados ou apagados em até 30 dias, conforme as políticas dos Serviços de API do YouTube. Também é possível pedir a exclusão pelo contato abaixo.
